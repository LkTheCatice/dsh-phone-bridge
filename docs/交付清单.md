## 二、App 与配套（AltStore 路径）的配合点

| 环节 | 是否自动 | 说明 |
|---|---|---|
| 重签 | 手动一次 | AltStore/Sideloadly 用你的 Apple ID 签；之后 AltStore 每 7 天自动续 |
| 版本可见 | 自动 | App 设置页底部显示 `build=64b86c7.134`，报障时让对方报这个 |
| 签名到期预警 | 自动 | App 读 `embedded.mobileprovision` → 设置页显示剩余天数（≤2 天转橙），同时上报电脑端面板 |
| 配对 | 手动一次 | `node bridge\bin\pairing.mjs` → 粘 `dshnb://` 串 |
| 续签后是否要重配 | 否 | **覆盖安装**不清 Keychain，配对与记录都在 |
| 换电脑 | 需重配 | 不同机器的 token 不同 |

## 四、转交时最容易断的三处（已提前处理）

1. **PowerShell 中文乱码** → 三个 `.ps1` 统一存成 UTF-8 **with BOM**
2. **`lanHost` 写死导致换网连不上** → 改为启动时自动探测（`os.networkInterfaces`），`pairing.mjs` 同步
3. **`roots` 默认空 → 手机读不到任何文件** → `install.ps1 -Roots` 直接写进配置，缺省时明确警告

## 五、验收命令（给使用者的一页速查）

```powershell
# 电脑
git clone https://github.com/<you>/dsh-phone-bridge && cd dsh-phone-bridge
powershell -ExecutionPolicy Bypass -File .\tools\preflight.ps1          # 环境预检
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Roots "D:\out"  # 装桥（然后重启 DSH）
node bridge\bin\pairing.mjs                                            # 拿配对串

# 手机：Sideloadly / AltStore 装 Release 里的 IPA → 粘配对串

# 自检（可选）
node tools\pentest.mjs --run
node tools\privacy-audit.mjs
```
