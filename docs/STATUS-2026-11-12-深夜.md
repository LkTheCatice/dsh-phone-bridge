## 六、已踩过的坑（别再犯）

**① 接口不确定就逆向**（AGENTS.md §7）
`updateQueue` 猜了七轮 ≈ 两小时；读 asar 里的 zod schema 三分钟。

**② 布局改动先想约束会不会打架**
气泡间距失效是因为 `topConstraint` + `stack.top == contentView.top` 两条同时生效。

**③ 拆 store 必须检查所有订阅者都注入了**
`WalletStore` 拆出去后 `SettingsView` 声明了 `@EnvironmentObject` 但没注入 → 点设置页闪退。编译期查不出来。

**④ configure 阶段 bounds 是 0**
气泡宽度按 `contentView.bounds.width` 算 → 那时是 0 → 宽度 0 → 文字全被裁掉（表现为「历史消息全看不见」）。

**⑤ 字符串 replace 之后要验证替换结果**
`formatMoney` 和 `walletUsageUrl` 两次都是「方法加进文件了，但调用点没改」，因为 replace 的目标字符串写错、又没检查。今天这个错犯了两次。

**⑥ 不要忽略自动触发的 CI**
`git push` 会触发 GitHub Actions，它在偷偷烧额度。看构建要两边都看。
