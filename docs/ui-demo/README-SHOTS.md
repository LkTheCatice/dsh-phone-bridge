# 镜头素材使用说明（给执行方）

脚本：`docs/video-script-apple.md`
素材渲染器：`shots.html`（**单文件、零依赖**，双击就能开）
镜头清单：`shots.json`（每镜的 URL 参数、对应脚本时间码、建议文件名）

---

## 1. 三步拿到素材

### ① 打开渲染器
浏览器打开 `shots.html`，默认显示第 03 镜第 0 秒。
URL 参数说明：

```
shots.html?shot=04&t=1.2          第 4 镜、镜内第 1.2 秒（推荐做静帧）
shots.html?shot=11&t=2&wide=1     第 11 镜，手机缩小（对应脚本的后退构图）
shots.html?shot=07&t=1&phone=1    只输出手机屏幕 945×2048（竖版用）
shots.html?shot=03&play=1         自动从 0 播到本镜结束（录屏用）
```

`shot` 与脚本的对应（`shots.json` 里有同样内容，可给机器读）：

| shot | 脚本时间 | 内容 | 默认字幕 |
|---|---|---|---|
| 01 | 0–4s | 黑场起 | — |
| 02 | 4–8s | 开屏 | 手机上的 DeepSeek Harness |
| 03 | 8–13s | 运行中（log 逐条） | 不用回头问电脑 |
| 04 | 13–18s | 收成折叠卡片 | 结束，也不消失 |
| 05 | 18–23s | 点开过程页 | — |
| 06 | 23–28s | 逐条高亮 | 每一步，都在 |
| 07 | 28–33s | 步骤详情 + 图 | 连它看过的图 |
| 08 | 33–37s | 图全屏 | — |
| 09 | 37–42s | 产物三连卡 | 产出，一眼看到 |
| 10 | 42–46s | md 预览 / zip 下载 | 能看的直接看，不能看的取回 |
| 11 | 46–52s | 后退到黑场 | 电脑在跑 · 手机在看 |
| 12 | 52–60s | 品牌收尾 | DSH Helm / 端到端加密 · 电脑执行 |

### ② 导静帧（不需要装任何东西）
Windows 一条命令导一张：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --headless=new --disable-gpu --hide-scrollbars `
  --window-size=1920,1080 `
  --screenshot="D:\out\S04_折叠卡片.png" `
  "file:///D:/Documents/deepseek-harness/default-workspace/phone-dsh/docs/ui-demo/shots.html?shot=04&t=1.2"
```

批量导：`export-shots.ps1`（同目录）已按 `shots.json` 写好全部静帧，
直接跑一次就能得到 `out/` 下十几张图。

### ③ 录动效（镜头里的"动"）
按脚本要有运动的部分（03 逐条落下、04 收拢、05 推入、07 滑入、09 三连卡）：

1. 浏览器打开 `shots.html?shot=03&play=1`
2. 用 **OBS 窗口采集** 或系统录屏，框住 1920×1080 整个页面（不要带浏览器边框）
3. 60fps 录制，录满本镜时长即可
4. 若需要更精确的帧，可在控制台调用 `window.setShotTime(1.234)` 逐帧定位

> 时间轴是 `t` 的函数，**同一 `t` 永远渲染同一帧**，所以重录、补帧都不会错位。

## 2. 剪辑时间轴怎么摆

按脚本把导出的素材丢到对应位置即可，几点约定：

1. **每镜的静帧都用"落定后"的那一帧**（`shots.json` 里的 `stills[].note` 标了）
2. **字幕不要用渲染器里的**（`shots.html` 自带字幕只是为了对构图）；成片字幕请按脚本第 4 节文案在剪辑软件里重排 —— 字号 56px / 28px，纯白细体，左 1/8
3. **不要给素材加阴影、发光、倒影**：Apple 产品片的"高级感"来自纯黑与留白
4. 手机屏幕边缘如果有 1px 白边，是圆角裁切的抗锯齿，剪辑里叠一层 1px 黑描边即可隐藏

## 3. 竖版（9:16）怎么取

一律用 `phone=1` 导 **945×2048** 的屏幕画面，再放进竖屏构图：

```
竖屏 1080×1920：
  · 手机占高 78%（≈1500px），居中偏下
  · 上方留 300px 黑场放字幕（28–32px，两行内）
  · 不用 stage 模式，一次只导屏幕
```

对应镜头：`02 03 04 06 07`（与脚本 15s 竖版一致）。

## 4. 素材与真机的关系

- 渲染器里的界面是**按真机设计令牌复刻**的：气泡圆角 14、卡片圆角 9 / 内边距 8·12、
  log 等宽 12、思考两行截断、`可预览 / 下载` 标签位置一致
- 如果你有真机录屏，**优先用真机**；这份渲染器用于：
  - 需要重复录同一个动作（对齐帧）
  - 真机状态栏/时间/电量不好统一时
  - 竖版重新构图
- 两者可以混用：UI 用渲染器、鼠标操作感用真机录制的"点击高亮"
