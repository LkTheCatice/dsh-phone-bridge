DSH Helm

用 iPhone 遥控电脑上的 DeepSeek Harness

手机发一句话，电脑上真实执行（跑命令、改文件、调工具），思考与工具调用流式回到手机； 动手前你在手机上点头或拒绝。内容端到端加密，默认只在你自己的局域网内直连。

它是什么

DSH Helm（仓库名 dsh-phone-bridge）是一个 iOS 客户端加电脑端插件， 把 DeepSeek Harness 变成可以在手机上远程操控的 AI 执行端。 它不是聊天 App，也不是远程桌面 —— 是「AI 的执行遥控器 + 验收面板」。

和串流 / 远程桌面的区别

串流（Parsec / ToDesk / Moonlight）DSH Helm
传什么屏幕画面 + 触控语义过程：指令、工具调用、产物
带宽5–50 Mbps几十 KB/s
能做什么操作整台电脑只操控 DSH 会话（更小的暴露面）
怎么改东西亲手改审阅 → 一句话让它改

怎么装

  1. 电脑：git clone 后跑 install.ps1，重启 DSH
  2. 手机：AltStore 加源装（能自动续签）或 Sideloadly 装 Release 里的 IPA
  3. 配对：node bridge\bin\pairing.mjs 拿到串，粘到 App 里

安全

每个请求/响应体都是 AES-256-GCM 密文，X25519 握手，AAD 绑定方法与路径（防跨端点重放）； 文件访问有根目录白名单；/admin 只允许本机。 安全须知 →
