# DSH Helm · 宣传片脚本（Apple 产品片风格 · 60s 母版）

> 面向执行方：这份文档按"分镜 + 视听语法 + 技术规范"写，**照做即可出片**，不需要再猜风格。
> 素材基线：真机 `dist/DSHRemote-unsigned.ipa`；可交互演示 `docs/ui-demo/index.html`（`Demo.*` API 见其 README）。
> 不做 PPT，最终交付是视频文件。

---

## 0. 气质参照（只描述，不点名品牌）

三条底层规则，违反任何一条都会"不像"：

1. **黑场呼吸**：全片背景是纯黑（#000），产品（手机）是唯一的光源。黑场不是"空"，是留白。
2. **慢即是贵**：镜头平均 3–5 秒，运镜只有两种——极慢推进（2–6% 缩放）和固定。不做甩镜、不做转场特效。
3. **一句话**：每屏最多 8 个汉字。不解释功能，只说结果。文案出现即静音环境，只留低频。

音色统一：低频 sub pulse（45–60 Hz）+ 材质音（玻璃轻触、金属吸附）+ 极短点击声。**没有鼓点、没有旋律**。

## 1. 视听语法（执行方必须先读）

### 画面
| 项 | 规格 |
|---|---|
| 画幅 | 16:9 / 3840×2160 母版，同时输出 1920×1080 |
| 帧率 | 60fps 拍摄与合成（Apple 产品片惯用），30fps 另出一版 |
| 背景 | 纯黑 #000000，不允许渐变、不允许噪点纹理（除非做颗粒质感时才用 3% 颗粒） |
| 手机露出 | 只露正面，正视、零畸变；屏幕边缘不允许出现反光斑 |
| 屏幕亮度 | 录制时 100%，后期不要再拉高，避免过曝泛白 |
| 色彩 | 屏幕内容保持 sRGB 原色；整体对比 +8，黑位压死（黑场必须真黑） |
| 景深 | 手机在焦点，背景全虚。微距镜头拍屏幕时用 f/2.8 以下 |

### 运镜
- **推进（Push）**：起点 100% → 终点 104~106%，线性或 ease-out，全程无抖动
- **固定（Lock）**：三脚架/滑轨静止，只有屏幕内容在动
- **禁止**：环绕、手持、变焦、横移过快（>200px/s）

### 文字（系统字体，细字重）
| 层级 | 字号（1080p 下） | 字重 | 位置 | 出现方式 |
|---|---|---|---|---|
| 主张 | 56–64 px | Regular | 画面左 1/8，垂直居中 | 淡入 0.4s，停 1.2s，淡出 0.3s |
| 说明 | 28–32 px | Light | 主张下方 24 px | 随主张一起淡入 |
| 品牌 | 40 px | Medium | 画面居中 | 只出现在片尾 |

中文用苹方（PingFang SC），英文用 SF Pro Display。字间距 +2%，绝不加粗。

### 声音
| 时机 | 声音 | 说明 |
|---|---|---|
| 黑场进入 | sub pulse 一记（-18 dB） | 每镜切换都可复用 |
| 文字出现 | 极轻 airy pad（无音高） | 0.6s |
| 手指操作 | 玻璃轻触（-24 dB） | 只在"点"的瞬间，不要连击声 |
| 卡片吸附/折叠 | 金属吸附（-20 dB） | 短，<120ms |
| 图片出现 | 极短胶卷/纸页声（-26 dB） | 一次即可 |
| 全片底噪 | 房间静音级 | 不要加"科技感"whoosh |

## 2. 60 秒母版 · 12 个镜头

> 时间码按 60fps；括号内是帧号。每个镜头都写了「拍什么 / 怎么动 / 出什么字 / 什么声」。

### 01 · 0.0–4.0s（0–240f）｜黑场 → 一束光
- **画面**：纯黑。第 0.6s 起，画面中央缓缓浮起手机的**屏幕反光切边**（只是一道 2px 的高光边，不露机身）。
- **运镜**：固定。只有高光边在 4 秒内从 0 提亮到 100%。
- **文字**：无。
- **声音**：sub pulse 一记（0.0s），随后 4 秒静音。
- **用意**：把"要出现的东西"藏起来，是最贵的开场。

### 02 · 4.0–8.0s（240–480f）｜开屏
- **画面**：手机正面从下方 6% 处极慢升起（ease-out，8 秒走完，本镜只走 1/3），屏幕上是开屏：白底、`DSH Helm` 图标弹入 → 标题淡入。
- **运镜**：极慢推进 100% → 103%。焦点在屏幕。
- **文字**：`DSH Helm`（品牌级，56px，左下）+ 下方 28px 一行 `手机上的 DeepSeek Harness`
- **声音**：图标出现时玻璃轻触（4.6s）；文字淡入时 airy pad。
- **细节**：开屏停留 2.3s、淡出 0.5s —— 与 App 实际行为一致，不要为了节奏剪短。

### 03 · 8.0–13.0s（480–780f）｜它已经在干活
- **画面**：屏幕内容切入对话页（已排好、停在最底部）。**思考行与工具行一条条落下**（每 0.35s 一条），文字是等宽灰色。
- **运镜**：固定。
- **文字**：`不用回头问电脑`
- **声音**：每条 log 落下配一记极轻的"打字尾音"（-30 dB），共 5 条。
- **用意**：先给"活着"的感觉，再讲功能。

### 04 · 13.0–18.0s（780–1080f）｜收成一行
- **画面**：所有 log 在同一位置收拢、淡出，落成一张**主题色卡片**：`▸ 本轮过程 · 10 步 ›`。卡片出现后轻微 1.02 → 1 回弹（0.2s）。
- **运镜**：推进 +2%（13s→18s 连续）。
- **文字**：`结束，也不消失`
- **声音**：金属吸附（卡片落定那一刻）；收拢过程有一声短促吸气感（-28 dB）。
- **细节**：卡片的圆角、内边距、字号必须与真机一致（9pt 圆角 / 上下 8 / 左右 12 / 13pt 中等字重）。

### 05 · 18.0–23.0s（1080–1380f）｜点开
- **画面**：手指未入镜，用一枚**半透明圆形高亮**（半径 22px，白色 25%）在卡片上轻点一次，卡片按压反馈 0.12s。画面推入「本轮过程」页（整页从下 100% 上滑，0.34s）。
- **运镜**：随页面推入同步 +4% 推进。
- **文字**：无（让页面自己说话）
- **声音**：玻璃轻触 + 页面推入的风声极短（-30 dB）。

### 06 · 23.0–28.0s（1380–1680f）｜逐条
- **画面**：过程页列表：`1 思考` / `2 运行命令` / `3 读取` / `4 写入`，每条带摘要与绿色对勾。高亮在第 1→4 行之间自上而下缓慢移动（每行 0.5s）。
- **运镜**：固定，只做 3% 推进。
- **文字**：`每一步，都在`
- **声音**：每次高亮移动一记极轻 tick（-34 dB）。

### 07 · 28.0–33.0s（1680–1980f）｜点第 3 行
- **画面**：高亮停在 `3 读取`，轻点。详情页从右侧滑入（0.28s）。上半是参数块（深色卡片、等宽小字），下半是**一张图片**——DSH 当时真正读过的图。
- **运镜**：这一段允许一次**微距推进**：100% → 108%，焦点跟着图片走。
- **文字**：`连它看过的图`
- **声音**：图片出现时一记纸页/胶卷声；其余静音。

### 08 · 33.0–37.0s（1980–2220f）｜图放大
- **画面**：轻点图片 → 全屏大图（0.3s 缩放 0.96→1）。图停留 2s。这是全片唯一"满屏非黑"的镜头，用来做视觉高点。
- **运镜**：固定。
- **文字**：无。
- **声音**：完全静音 1.5s（留白），最后 0.5s 起低频。

### 09 · 37.0–42.0s（2220–2520f）｜产物
- **画面**：返回对话页（0.3s 横滑）。三张产物卡片依次落下（间隔 0.4s）：
  `🖼 案例图.png  可预览` → `📝 晨报.md  可预览` → `🗜 素材.zip  下载`
- **运镜**：固定 + 2% 推进。
- **文字**：`产出，一眼看到`
- **声音**：每张卡片落下一次金属吸附（音高逐次 +1 半音，形成三个音的小动机）。

### 10 · 42.0–46.0s（2520–2760f）｜能看 / 不能看
- **画面**：轻点 `.md` → 正文预览（等宽、可读）；0.6s 后返回；再点 `.zip` → 底部弹出下载/分享面板。
- **运镜**：固定。
- **文字**：`能看的直接看，不能看的取回`
- **声音**：面板弹出时一记极轻的"滑出"声。

### 11 · 46.0–52.0s（2760–3120f）｜回到黑场
- **画面**：手机整体后退、缩小到画面 55%，周围回到纯黑。屏幕上只剩底栏的状态点（绿点）微微呼吸。
- **运镜**：缓慢后退 100% → 92%（ease-in-out）。
- **文字**：`电脑在跑 · 手机在看`
- **声音**：底噪渐起，sub pulse 每 2 秒一记。

### 12 · 52.0–60.0s（3120–3600f）｜品牌收尾
- **画面**：手机淡出，只剩黑底与居中品牌字。第 56s 起，品牌字下出现一行细体说明。
- **文字**：
  - `DSH Helm`（40px Medium，居中，52–60s 常驻）
  - `端到端加密 · 电脑执行`（28px Light，56s 淡入）
- **声音**：最后一次 sub pulse（57s），之后静音到结束（不要 fade out 音乐，直接干净切断）。

## 3. 30s 与 15s 剪法（从母版直接裁）

### 30s（投放：官网首屏 / 展会开场）
保留镜头 **02 / 03 / 04 / 06 / 07 / 09 / 12**，删掉细节操作（05、08、10、11）。
时间分配：02(3s) 03(4s) 04(4s) 06(4s) 07(5s) 09(5s) 12(5s)。
文字同步精简为四句：`手机上的 DeepSeek Harness` / `不用回头问电脑` / `结束，也不消失` / `电脑在跑 · 手机在看`。

### 15s（投放：竖版信息流，9:16 需重新构图）
切四段，每段 3–4s，**全部竖构图**：手机占画面 78%，文字在手机上方留白处。
1. 开屏 → 停在底部（文字：`它在跑`）
2. log 落下 → 收成卡片（`过程不会消失`）
3. 点卡片 → 过程页（`每一步都在`）
4. 点第 3 行 → 看到图（`连它看过的图`）
竖版不做片尾品牌板，最后 0.8s 叠一个小 logo 即可。

## 5. 拍摄与制作规范

### A. 屏幕内容怎么来（两种，任选）
1. **真机录制**（推荐，最真）
   - iPhone「屏幕录制」60fps；录之前：亮度 100%、专注模式开、状态栏电量固定 100%（或后期替换状态栏）
   - 录完把视频放进手机模型（`Screen Replacement`）里，模型用黑壳、无 logo、正面正视
2. **HTML 复刻**（可控、可重录）
   - `docs/ui-demo/index.html` 里 `Demo.*` 逐个调用，Playwright 只截 `#phone` 元素，2x 像素密度
   - 优点：同样的动作能录 10 遍都一样，方便对齐

### B. 后期
- 所有 UI 素材**不要**再加阴影/发光/倒影；Apple 产品片的"高级感"来自黑场与留白
- 文字动画统一：opacity 0→1（0.4s）+ 上移 8px，无弹跳、无缩放
- 黑场用纯 #000，不要用 RGB(10,10,12) 这种"伪黑"

### C. 屏幕内容与文字的关系
- 文字**绝不压在屏幕上**，只出现在黑场留白区
- 同一镜内文字只出现一次，不重播

## 8. 禁止项（会立刻"不像"）

- ❌ 任何渐变背景、科技蓝光效、粒子、网格线
- ❌ 快切、甩镜、转场特效（wipe/zoom/flip）
- ❌ 出现人脸、手部特写（只用高亮圈代替手指）
- ❌ 屏幕上叠加箭头、圆圈标注、放大镜
- ❌ 承诺"自动修复 / 全自动 / AI 帮你写完"——产品做的是**观察与控制**
- ❌ 使用非真实界面（P 图、假数据、假 log）
