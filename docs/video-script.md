# DSH Helm 宣传片脚本

> 素材基线：`dist/DSHRemote-unsigned.ipa`（真机截图见 `docs/deck/img/`）、
> 可交互演示 `docs/ui-demo/index.html`、PPT 第 11 页做引导。
> 所有画面都是真实界面，不摆拍、不夸大功能。

---

## 0. 规格

| 项 | 45s 主片 | 15s 竖版 | 8s 循环 |
|---|---|---|---|
| 画幅 | 1920×1080（16:9） | 1080×1920（9:16） | 1080×1080 |
| 帧率 | 30fps | 30fps | 30fps |
| 投放 | 官网 / B站 / 演示开场 | 朋友圈 / 抖音 / 小红书 | 展台循环 |
| 基调 | 冷静、克制、像工具不像玩具 | 同左，节奏更快 | 纯视觉，无旁白 |
| 音乐 | 低频脉冲 + 轻钢琴，90 BPM | 同曲加速段落 | 环境 pad |

**一句话主张**：让手机成为一双眼睛和一只手，但活仍然在电脑上跑。

## 1. 45 秒主片

### Shot 01 · 0:00–0:04｜开屏（0.0–4.0s）
- **画面**：手机冷启动。白底 → `DSH Helm` 图标弹入（0.94→1 缩放）→ 标题淡入 → 停 2.3s → 淡出到已排好的对话页，**直接停在最底部**。
- **文案**：无（只出产品名与副标题）
- **旁白**：无
- **音效**：一声很轻的“叮”（进入瞬间）
- **要点**：这段必须剪干净——全片唯一允许的“空白”，用来建立品牌。

### Shot 02 · 0:04–0:10｜场景：人不在电脑前（4.0–10.0s）
- **画面**：分屏。左侧电脑屏幕跑着日志（快放、失焦），右侧手机同一时刻亮起。手机屏幕上出现「思考」行与「运行命令」行，逐条落下。
- **屏幕文字**：`它现在在做什么，不用回头问电脑`
- **旁白**：不在电脑前的时候，你最想知道的其实是——它到底在干什么。
- **音效**：键盘敲击极轻的底噪，随后戛然而止（对应“抬头看手机”的停顿）

### Shot 03 · 0:10–0:18｜过程可回看（10.0–18.0s）
- **画面**：手机特写。运行中的 log 一行行滚过（思考 / 运行命令 / 读取 / 写入）。一轮结束，所有 log **收成一张卡片**：`▸ 本轮过程 · 10 步 ›`。手指点它。
- **屏幕文字**：`结束后不消失，收成一行`
- **旁白**：跑完之后，这些日志不会消失，它们收成一行，随时可以再打开。
- **节奏**：折叠动作给 3 帧以内的“吸附感”，卡片出现时轻微 scale 1.02 → 1。

### Shot 04 · 0:18–0:26｜每一步都能下钻（18.0–26.0s）
- **画面**：「本轮过程」页推入。四行过程条目，序号 + 图标 + 摘要 + 绿色对勾。手指点第 3 行（读取）。
- **屏幕文字**：`点开任意一步`
- **旁白**：每一步都能点开，看它调了什么、拿到什么结果。
- **节奏**：列表推入用 `push`，跟 PPT 第 6 页同一条动线。

### Shot 05 · 0:26–0:33｜它看过的东西（26.0–33.0s）
- **画面**：步骤详情滑出。上半是参数 JSON，下半是**一张图片**（DSH 当时读的那张）。手指点图 → 大图。
- **屏幕文字**：`连它看过的图，也在里面`
- **旁白**：包括它读过的图——出问题时，第一句话往往是“它到底看了什么”。
- **音效**：图片出现时一记很轻的“胶卷”声

### Shot 06 · 0:33–0:40｜产物（33.0–40.0s）
- **画面**：回到对话页。三张产物卡片依次落下：
  `🖼 案例图.png 可预览` → `📝 晨报.md 可预览` → `🗜 素材.zip 下载`。
  手指点 `.md` → 看到正文；返回，点 `.zip` → 弹出下载分享。
- **屏幕文字**：`产出什么，一眼看到`
- **旁白**：产出的文件会直接变成卡片：能看的点开就看，不能看的取回手机。
- **节奏**：三张卡各 0.4s 间隔，落位用 ease-out，不要弹跳。

### Shot 07 · 0:40–0:45｜收尾（40.0–45.0s）
- **画面**：拉远到手机 + 电脑同框；手机屏幕淡出成纯色，出现 logo 与一行字。
- **屏幕文字**：`DSH Helm` / `电脑跑活 · 手机看着它干` / `端到端加密`
- **旁白**：活还在电脑上跑，端到端加密。你只需要一部手机。
- **音效**：音乐收尾留 0.5s 尾巴

## 2. 15 秒竖版（信息流）

| 时间 | 画面 | 屏幕文字 |
|---|---|---|
| 0.0–3.0s | 开屏 → 直接停在对话底部 | `电脑在跑，手机在看` |
| 3.0–7.0s | log 逐条落下 → 收成 `▸ 本轮过程 · 10 步 ›` | `过程不会消失` |
| 7.0–11.0s | 过程页 → 点某步 → 详情里的**那张图** | `连它看的图都能点开` |
| 11.0–15.0s | 产物卡片 3 连落 → 点 `.md` 预览 | `产出即卡片：可预览 / 下载` |

**旁白（可省，仅留字幕）**：
> 电脑在跑，手机在看。过程收成一行，点开就是每一步；连它看过的图都在里面。

## 3. 8 秒循环（展台）

无旁白、无字幕，只留三件事：

1. 0–3s：log 逐条落下（快放 1.5×）
2. 3–5.5s：收成折叠卡片
3. 5.5–8s：卡片点开 → 过程页 → 详情里的图（0.8s 停留）

## 5. 录制清单

| 需要拍/录 | 来源 | 备注 |
|---|---|---|
| 开屏 2.3s | 真机冷启动，或 `docs/ui-demo/index.html` → `Demo.replayLaunch()` | 必须包含“到已排好的对话页”那一下 |
| log 逐条落下 | 真机跑一轮，或 `Demo.streamThinking()` + `Demo.streamTools()` | 若用网页版，帧率更稳 |
| 收尾折叠 | 真机 turn.end，或 `Demo.finishTurn()` | 卡片出现后停 0.5s |
| 过程页 | 真机点卡片，或 `Demo.openTurnLog()` | 页面推入要录完整 |
| 步骤详情 + 图片 | 真机点第 3 行，或 `Demo.openStep(2)` | 图片必须是**DSH 读过的图**，别用素材图 |
| 产物卡片 | 真机让 DSH 产出 `.md/.zip/.png` | 三种类型的标签各出现一次 |
| 电脑侧背景 | 屏幕录制，快放 200% | 失焦、适度模糊即可 |

**拍片禁忌**：

- 不要用非真实截图（比如自己 P 的界面）——这版界面的细节（两行思考、可预览标签）就是卖点
- 不要露出右侧控制面板（网页演示用 Playwright 只截 `#phone`）
- 不要承诺“自动修 bug / 全自动”——它做的是**观察与控制**
