# 部署（电脑侧）

## 0. 前置

- **Node ≥ 24**（插件零依赖，不用装任何包；但读会话历史用到 `node:zlib` 的 zstd，24 才有）
- 已安装并**至少启动过一次** DeepSeek Harness 桌面版
- 知道自己的 DSH profile 名（默认 `desktop`；跑一次预检会列出来）

先跑预检，缺什么会直接说：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\preflight.ps1
```

## 1. 装插件

**推荐**（仓库根目录，一条命令，先预检再装）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Roots "D:\work\output"
```

等价的老路径（在 `bridge\` 里跑也可以）：

```powershell
cd phone-dsh\bridge
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

`-Roots` 是手机**允许读写的目录**，不填的话手机读不到任何文件。

> 必须带 `-ExecutionPolicy Bypass`：默认执行策略会拒绝未签名脚本。
> 脚本本身是 UTF-8 带 BOM 保存的，PowerShell 5.1 才不会把中文注释读坏。

它会做四件事：

1. 在 `%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-phone-bridge` 建 **junction** 指向仓库（C 盘 0 字节；失败自动退回复制）
2. 备份 `cordis.patch.yml`（后缀 `before-phone-bridge-<时间戳>`）
3. 追加一条 `phone-bridge` 配置（幂等：已有就跳过）
4. 打印配对串

参数：

```powershell
.\install.ps1 -Profile web                       # 装到 web profile
.\install.ps1 -LanHost 192.168.1.23              # 固定内网 IP（不填=自动探测）
.\install.ps1 -Roots "D:\out","E:\work"          # 多个白名单目录
.\install.ps1 -Link:$false                       # 不建链接，直接复制
.\install.ps1 -Port 8899                          # 换端口
```

## 2. 重启 DeepSeek Harness

**完全退出**（托盘图标右键退出，任务管理器里确认没有残留进程），再打开。

成功标志：启动日志里出现

```
[phone-bridge] 监听 127.0.0.1:8765
[phone-bridge] 配对串: dshnb://pair?host=127.0.0.1&port=8765&token=…&fp=…
```

## 3. 验收（不装手机也能验）

```powershell
cd phone-dsh\bridge
# 凭据如果不在默认位置，先指过去
$env:DSH_PHONE_BRIDGE_DIR = 'D:\Documents\deepseek-harness\dsh-phone-bridge'
node .\bin\smoke.mjs
```

`smoke.mjs` 只读凭据，不会生成新的 —— 所以凭据缺失时它会明确报错并告诉你先重启 DSH，而不是悄悄造一套把线上实例顶掉。

期望输出：

```
  health  v0.2.35 · e2eeRequired=true
  握手  clientId=xxxxxxxx…
  指纹校验  一致
  密钥  X25519 + HKDF-SHA256 派生完成
  解密  235 字节
  会话  N 个
  文件根  1 个：…
  待审批  0
  越界防护  403 已拒绝

✓ 链路正常。手机 App 用同一串配对即可。
```

任何一步失败都会以非零码退出并说明原因。

## 4. 选一条通道

### A. Tailscale（推荐，外网也能用）

```powershell
# 电脑与手机装同一个 tailnet
tailscale serve --bg --https=443 8765
tailscale serve status
```

得到 `https://<机器名>.<tailnet>.ts.net`。

- Tailscale 会自动签发 ts.net 证书，iOS 不用改 ATS
- 插件仍只听 loopback，公网看不到 8765
- 手机端 App 里 `useTLS` 会自动置 true（host 以 `.ts.net` 结尾）

配对串要用 ts.net 域名：

```powershell
node .\bin\pairing.mjs <机器名>.<tailnet>.ts.net 443
```

### B. 只走局域网

```powershell
.\install.ps1 -LanHost 192.168.1.23
```

重启后监听 `192.168.1.23:8765`。传输是明文 HTTP，但**每个请求体都是 AES-256-GCM 加密的**，同网段抓包只能看到长度与时序。

配对串：

```powershell
node .\bin\pairing.mjs 192.168.1.23 8765
```

## 5. 配置项（`cordis.patch.yml`）

```yaml
- insert:
    - id: phone-bridge
      name: dsh-phone-bridge
      config:
        port: 8765                  # 监听端口
        lanHost: "192.168.1.23"     # 内网 IP；留空只监听 loopback（纯 Tailscale 模式）
        askPhone: true              # 是否让手机参与审批
        approvalTimeoutMs: 90000    # 手机不应答多久后交回桌面端
        requireE2ee: true           # 强制端到端加密（不建议关）
        stateDir: 'D:\dsh-phone-bridge'   # token / 密钥 / bridge.log 放在哪；
                                          # 留空时**默认就是插件自己的目录**（<插件目录>\dsh-phone-bridge），
                                          # 不是 %USERPROFILE%\.dsh —— 排查问题时别去那边找
        maxFileBytes: 536870912     # 单文件上限 512 MiB
        roots:                      # 额外允许手机读写的目录
          - D:\Documents\分享
        notify:                     # 完成通知（可留空）
          kind: bark                # "" | "bark" | "ntfy"
          server: ""                # 留空用 https://api.day.app 或 https://ntfy.sh
          key: "<你的 bark device key>"
          topic: ""                 # ntfy 用
```

`lanHost` 填了内网 IP 之后，手机在同一 Wi-Fi 下连 `http://<该IP>:8765`；IP 变了（DHCP）要改这一行再重启。

改完同样要重启 DSH。

## 6. 日常操作

```powershell
# 看配对串与已连接过的手机
node bridge\bin\pairing.mjs --json

# 轮换 token（所有手机要重新配对，已握手会话立即断开）
node bridge\bin\pairing.mjs --rotate

# 清空设备名单（token 不变）
curl -X POST http://127.0.0.1:8765/v1/admin/unpair -H "x-dsh-token: <token>"
```

## 7. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 日志里没有 `[phone-bridge]` | 插件没加载 | 确认 `cordis.patch.yml` 里有 `phone-bridge` 段；确认只重启了 GUI 没杀进程 |
| `EADDRINUSE` | 端口被占 | 改 `port`，或找占用的进程 |
| 手机连不上、健康检查也不通 | 通道不对 | 先在本机 `curl http://127.0.0.1:8765/v1/health`；再确认 tailscale 状态 |
| 401 `e2ee-required` | 客户端没握手就发请求 | App 会先握手；自己写脚本时别忘了 `/v1/handshake` |
| 401 `handshake-required` | clientId 过期 | 重新握手（App 会自动做） |
| 403 路径不在允许的根目录内 | 白名单 | 把目录加进 `roots` 并重启 |
| 手机端收不到流 | SSE 被代理缓冲 | `tailscale serve` 无此问题；自建反代要关 buffering |
| 电脑卡在"等确认" | 手机不在线时不会拦 | 检查 App 是否在前台、`askPhone` 是否为 true |

## 8. 卸载

```powershell
cd phone-dsh\bridge
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
Remove-Item -Recurse -Force "$env:USERPROFILE\.dsh\phone-bridge"   # 连凭据一起删
```

然后重启 DSH。
