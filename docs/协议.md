# 协议

给以后写 Android 客户端、脚本或调试用。实现参考：`bridge/index.js`（服务端）、`ios/DSHRemote/Sources/Net/`（客户端）。

## 传输约定

- 基址：`http://127.0.0.1:8765` / `http://<lan>:8765` / `https://<host>.ts.net`
- 鉴权头：`x-dsh-token: <token>`（也接受 `Authorization: Bearer <token>`；SSE 可用 `?token=`）
- 内容加密：`x-sealed: 1` + `x-client: <clientId>`；请求体与响应体都是二进制封包
- 除 `/v1/health`、`/v1/handshake` 外，**未加密请求一律 401 `e2ee-required`**

## 握手

```http
POST /v1/handshake
x-dsh-token: <token>
content-type: application/json

{ "clientPub": "<base64(32B X25519 raw)>", "clientName": "iphone" }
```

```json
{
  "ok": true,
  "v": 1,
  "clientId": "uuid",
  "serverPub": "<base64(32B)>",
  "fingerprint": "<base64url(sha256(serverPub))>",
  "client": "known" | "new",
  "knownClients": 2,
  "serverName": "win32/x64"
}
```

客户端必须校验 `sha256(serverPub)` 与配对串里的 `fp` 一致。

### 密钥派生

```
shared = X25519(clientPriv, serverPub)
okm    = HKDF-SHA256(ikm = shared, salt = utf8(token), info = "dsh-phone-bridge/v1", len = 64)
c2s    = okm[0..32)     # 加密请求体
s2c    = okm[32..64)    # 加密响应体
```

## 封包与 AAD

```
sealed = nonce(12) || AES-256-GCM ct || tag(16)      # 即 CryptoKit 的 .combined
AAD    = `${METHOD} ${PATH}?${canonicalQuery}`
```

`canonicalQuery`：按 key 升序，`encodeURIComponent(k)=encodeURIComponent(v)`，`&` 连接；无 query 时 AAD 不含 `?`。

`encodeURIComponent` 不编码 `A-Za-z0-9 - _ . ! ~ * ' ( )`。

**请求与响应用同一个 AAD**：发 `GET /v1/state` 就用 `GET /v1/state` 解响应。

## 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/v1/health` | 明文、无鉴权。**只回** `{ok, version, bridge, e2eeRequired}`（会话数/在线状态已移除：匿名端点不该泄露用量） |
| POST | `/v1/handshake` | 明文 + token |
| GET | `/v1/state` | `{sessions[], pending{approvals[],questions[]}, notify, roots[], lastSeq}` |
| GET | `/v1/sessions` | `{sessions[]}` |
| POST | `/v1/task` | `{text, sessionId?, mode?, requestId?}` → `{ok, sessionId, created, requestId, accepted}` |
| POST | `/v1/approval` | `{id, decision:"allow"\|"deny"}` |
| POST | `/v1/answer` | `{sessionId, text, requestId?}`（best-effort） |
| POST | `/v1/cancel` | `{sessionId}` |
| GET | `/v1/stream` | SSE，`?since=<seq>&client=<clientId>`；缺口时先发一条 `stream.gap` |
| GET | `/v1/diag` | **需要 token**，仅 loopback。帧直方图、卡顿统计、队列长度 |
| POST | `/v1/session/new` | `{cwd?}` → `{sessionId}`。cwd 只在是**已注册工作区**时才采用 |
| POST | `/v1/session/rename` | `{sessionId, title}` |
| POST | `/v1/session/archive` | `{sessionId, archived?}` |
| POST | `/v1/session/forward` | `{toSessionId, path? \| text?, note?, fromTitle?, attachCommand?}`。`path` 走白名单校验；3 秒内同目标同内容去重 |
| POST | `/v1/signing` | `{expiresAt?, daysLeft?}`。手机上报证书到期，电脑端据此提醒续签 |
| GET | `/v1/fs/list` | `?path=` → `{path, entries[{name,dir,link,size,mtime}]}` |
| GET | `/v1/fs/stat` | `?path=` |
| GET | `/v1/fs/read` | `?path=&offset=&limit=` → 二进制（默认 1 MiB/块） |
| POST | `/v1/fs/write` | `?path=&offset=&truncate=1` + 原始字节 |
| POST | `/v1/admin/rotate-token` | 换 token、清空所有 clientId。**所有 `/admin/*` 都需要请求头 `x-dsh-admin: 1`**（防跨站请求） |
| POST | `/v1/admin/unpair` | 清空设备名单 |
| GET | `/v1/admin/clients` | 设备名单 |

所有响应体（含错误体）都按同一 AAD 加密；错误体结构 `{error, message, detail?}`。

## SSE 帧

```
: ping                          # 心跳，15 s
event: sealed
data: <base64(AES-GCM(s2c, aad="SSE", json))>
```

未握手时退化为 `data: {json}`。

帧结构：

```json
{ "v": 1, "seq": 42, "at": 1730000000000, "type": "...", "sessionId": "session-..." }
```

### 帧类型

| type | 额外字段 |
|---|---|
| `turn.start` | `turn` |
| `assistant.delta` | `turn`, `text` |
| `assistant.thinking` | `turn`, `text` |
| `assistant.usage` | `turn`, `usage{input,output,cacheRead,total}` |
| `assistant.raw` | `turn`, `raw`（未知形状兜底） |
| `tool.call` | `turn`, `callId`, `name`, `args` |
| `tool.result` | `turn`, `callId`, `ok`, `preview` |
| `approval.asked` | `id`, `tool`, `reason`, `timeoutMs` |
| `approval.decided` | `id`, `decision` |
| `turn.end` | `turn`, `reason` |
| `user.message` | `turn`, `text` |
| `event` | `dshType`, `raw`（未归一化的原始事件） |
| `stream.gap` | `from`, `to`, `lost`。重连时 `since` 早于缓冲最老帧 → 这一段永久丢失，界面据此提示 |

服务端保留最近 **12000** 帧；断线后带 `since=<最后收到的 seq>` 重连即可补齐。
超出缓冲的部分不会再补 —— 此时会先收到 `stream.gap`（含丢失条数），随后是仍可用的增量。

## 错误码

| HTTP | error | 场景 |
|---|---|---|
| 401 | `unauthorized` | token 不对 |
| 401 | `e2ee-required` | 该端点必须加密 |
| 401 | `handshake-required` | clientId 未知/已过期 |
| 403 | `forbidden` | 路径不在白名单根内 |
| 404 | `not-found` | 端点不存在 / 审批已过期 |
| 413 | `payload-too-large` | 请求体超限（JSON 端点 16 MiB） |
| 429 | `too-many-attempts` | 同一来源 60 秒内认证失败 20 次后分档封禁（1 / 5 / 30 分钟，跨重启保留） |
| 400 | `outside-roots` | 转发/读写目标不在允许的根目录内 |
| 403 | `admin-header-required` | `/admin/*` 缺少 `x-dsh-admin: 1` |
| 503 | `not-ready` | `sessionController` 还没就绪（启动几秒内） |

## 最小可跑示例（Node）

```js
import crypto from "node:crypto";

const base = "http://127.0.0.1:8765";
const token = "<token>";
const fp = "<fingerprint>";

const client = crypto.generateKeyPairSync("x25519");
const der = client.publicKey.export({ format: "der", type: "spki" });
const clientPubRaw = der.subarray(der.length - 32);

const hs = await fetch(base + "/v1/handshake", {
  method: "POST",
  headers: { "x-dsh-token": token, "content-type": "application/json" },
  body: JSON.stringify({ clientPub: clientPubRaw.toString("base64"), clientName: "script" }),
}).then((r) => r.json());

const serverPub = crypto.createPublicKey({
  key: Buffer.concat([Buffer.from("302a300506032b656e032100", "hex"), Buffer.from(hs.serverPub, "base64")]),
  format: "der",
  type: "spki",
});
const shared = crypto.diffieHellman({ privateKey: client.privateKey, publicKey: serverPub });
const okm = Buffer.from(crypto.hkdfSync("sha256", shared, Buffer.from(token), Buffer.from("dsh-phone-bridge/v1"), 64));

// 之后按 AAD 规则自行封包；完整的收发实现见 bin/smoke.mjs
```
