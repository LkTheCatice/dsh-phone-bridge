# 续签：为什么只有 7 天，怎么不被它打断

## 为什么会过期

iPhone 上装**非 App Store** 的 App，必须由某个 Apple ID 签名。
用**免费** Apple ID（Sideloadly / AltStore 默认走这条）时，苹果给的描述文件有效期就是 **7 天**，
到期后系统直接拒绝启动 —— 表现是"点图标闪一下就没反应"，不是崩溃。

只有两种办法绕开：**自动续签**（每 7 天在后台重签一次）或**付费账号**（证书 1 年）。

---

## 方案一：AltStore / SideStore 自动续签（免费，推荐）

原理：电脑上跑一个常驻小服务（AltServer），手机和电脑在同一 WiFi 时，
手机会自动找它重签并刷新有效期 —— 你什么都不用做。

**步骤**

1. 电脑装 [AltServer](https://altstore.io/)（Windows 版），托盘常驻
2. 手机装 AltStore（用 AltServer 推到手机上，需要同一个 Apple ID）
3. AltStore → Settings → 打开 **Background Refresh**，填入你的 Apple ID
4. 保持"手机和电脑同一个 WiFi" + AltServer 在跑

**注意**

- 每 7 天必须至少有一次"手机和电脑在同一个 WiFi 且 AltServer 在跑"，否则照样过期
- AltStore 的 3 个 App 名额里，本 App 占 1 个
- [SideStore](https://sidestore.io/) 是免电脑的变体（需要一次性配对文件 + 一台常开的机器做 StosVPN）

## 方案二：付费开发者账号（99 美元/年）

- 证书 **1 年**，且可给最多 100 台设备
- 还能用 TestFlight 让别人装（不用每人自己签）
- Sideloadly / AltStore 里换成付费账号登录即可，流程不变

## 方案三：什么都不配，手动重装（最省事的"接受现实"）

每 7 天做一次，约 2 分钟：

1. 电脑打开 Sideloadly，把 `DSHRemote-unsigned.ipa` 拖进去
2. 输入 Apple ID，Start
3. 手机上信任该描述文件（设置 → 通用 → VPN与设备管理）

**重装不会丢数据**：聊天记录在电脑上，配对信息在手机 Keychain 里（Keychain 不随 App 删除清空，
但**卸载**会清 Keychain —— 所以尽量"覆盖安装"，不要先删再装）。

---

## App 会告诉你还剩几天

设置页 →「安装与签名」会显示真实到期时间（从 App 自己的 `embedded.mobileprovision` 里读）：

```
签名有效期   还剩 5 天（到期后 App 会打不开，需用 Sideloadly 重新安装）
```

剩 ≤ 2 天时这一行会变成橙色并给出提示 —— 别等到打不开才发现。

> 读不到描述文件时（比如从 Xcode 直接装、或企业证书）会显示"未检测到"，属正常。

## 常见问题

**Q：到期后打开就闪退，是 bug 吗？**
不是。系统在启动阶段就拒绝了未签名/过期签名的二进制。重签安装即可。

**Q：重装后要不要重新配对？**
一般不用 —— 只要**覆盖安装**（不先卸载），Keychain 里的设备私钥和 token 都还在。
如果先删了 App，Keychain 被清空，就要重新扫码配对。

**Q：能不能只续签不改 App？**
可以。Sideloadly 支持对已装 App 直接用同一 IPA 重新签一次（不要卸载）。

**Q：AltStore 装了但没自动续？**
检查：① 手机与电脑同一网段（有些路由器开了 AP 隔离）② AltServer 托盘在跑 ③ AltStore 的 Background Refresh 已开 ③ 手机没开低电量模式（会限制后台）。
