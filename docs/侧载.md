# 把 App 装进 iPhone（无 Mac、无开发者账号）

手上只有 Windows 时，路只有一条：**GitHub Actions 的 macOS 机器编译 → 拿未签名 ipa → 本地用 Apple ID 免费签名装上**。

免费签名的代价：**7 天过期**，到期重跑一次工作流、重装一次。这是 Apple 的限制，躲不掉。

## 1. 把项目推到 GitHub

```powershell
cd phone-dsh
git init
git add .
git commit -m "dsh phone bridge"
git branch -M main
git remote add origin https://github.com/<你>/<仓库>.git
git push -u origin main
```

私有仓库完全够用。Actions 免费额度：私有仓库每月 2000 分钟，这个工程一次编译约 3–5 分钟。

## 2. 跑工作流

推上去后打开仓库 → **Actions** → 左侧 `DSHRemote unsigned IPA` → **Run workflow**。

工作流做：

1. `brew install xcodegen`
2. `xcodegen generate`（从 `project.yml` 生成 `.xcodeproj`）
3. `xcodebuild ... CODE_SIGNING_ALLOWED=NO` 编译 Release
4. 把 `.app` 打进 `Payload/` 压缩成 `DSHRemote-unsigned.ipa`
5. 上传 artifact（保留 30 天）

成功后在该次运行页面底部下载 **DSHRemote-unsigned-ipa**。

> 首次编译大概率会暴露几处 Swift 类型问题（我没法在本机编译）。改完推上去重跑即可，报错行号会直接指到 `Sources/` 下具体文件。

## 3. 装到手机

### 3.1 Windows 上装 Sideloadly

- 下载：<https://sideloadly.io/>
- 电脑装 **iTunes**（微软商店版即可，Sideloadly 需要它的驱动）
- 数据线连 iPhone，信任这台电脑

### 3.2 用 Apple ID 签名

1. Sideloadly 里 `IPA` 选下载的 `DSHRemote-unsigned.ipa`
2. `Apple ID` 填你的 Apple ID
3. 点 Start，输入密码（会走 Apple 的 2FA，可能需要 App 专用密码）
4. 装完在手机上：**设置 → 通用 → VPN与设备管理 → 开发者应用** → 信任你的 Apple ID

### 3.3 允许局域网访问

首次连接时 iOS 会弹「DSH 遥控想查找并连接本地网络设备」→ 允许。否则局域网通道不通。

## 4. 7 天续命

到期后 App 打不开（闪退）。流程：

1. Actions 里重跑工作流（代码没变也能重跑）
2. 下载新 ipa
3. Sideloadly 重新装一次（覆盖安装，Keychain 里的配对信息**会保留**）

想省事：装 [AltStore](https://altstore.io/) 或 SideStore，让它在同一 Wi-Fi 下自动重签，就不用每周手动来了。

## 5. 有 Mac 的情况

```bash
brew install xcodegen
cd phone-dsh/ios/DSHRemote
xcodegen generate
open DSHRemote.xcodeproj
```

Xcode 里选你的 Apple ID 团队，真机运行即可。`project.yml` 里 `bundleIdPrefix: dev.yg` 可改成你自己的。

## 6. 编译报错怎么读

| 报错 | 通常原因 |
|---|---|
| `cannot find 'X' in scope` | `Sources/` 下文件没被 target 收录 —— `project.yml` 的 `sources: - path: Sources` 应自动包含全部 |
| `type 'X' does not conform to 'Sendable'` | Swift 6 严格并发；`SWIFT_VERSION` 保持 `5.9` 就是警告 |
| `HKDF`/`AES.GCM` 相关 | 确认文件里有 `import CryptoKit` |
| `NSAppTransportSecurity` 相关 | `project.yml` 的 `info.properties` 里已声明 `NSAllowsLocalNetworking` |
| `URLSession.bytes` 不可用 | 部署目标必须 ≥ iOS 15（本项目设 16.0） |

## 7. 不装 App 也能用（应急）

`dsh web` 本身可以暴露成 HTTPS 网页，Safari 里「添加到主屏幕」当 PWA 用：

```powershell
# 自己生成证书（需要 openssl；没有就跳过，改用 tailscale serve）
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365 -subj "/CN=dsh.local"

dsh web --host 192.168.1.23 --port 8443 --tls-cert cert.pem --tls-key key.pem --no-open --trusted-host 192.168.1.23:8443
```

优点：零开发。缺点：桌面版界面在手机上很难用、没有推送、没有原生文件选择。
